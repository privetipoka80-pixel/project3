# Интернет-магазин на Flask

Проект представляет собой веб-приложение интернет-магазина. В нем реализованы регистрация и авторизация пользователей, каталог товаров, карточки товаров с изображениями, отзывы, оформление заказов и отдельные возможности для продавца/администратора.

## Возможности проекта

- Регистрация и вход пользователей.
- Авторизация через Flask-Login.
- Разделение пользователей по ролям: обычный пользователь, продавец и администратор.
- Просмотр каталога товаров на главной странице.
- Просмотр подробной страницы товара.
- Добавление товаров продавцом или администратором.
- Редактирование и удаление товаров.
- Загрузка нескольких изображений для товара.
- Удаление отдельных изображений товара.
- Добавление отзывов и оценок к товарам.
- Редактирование и удаление собственных отзывов.
- Оформление заказа с указанием количества товара.
- Автоматическое уменьшение остатка товара после заказа.
- Просмотр списка своих заказов.
- Отдельная страница товаров продавца.
- Хранение данных в SQLite через SQLAlchemy.

## Установка и запуск

1. Создайте и активируйте виртуальное окружение:

```bash
python -m venv venv
venv\Scripts\activate
```

2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Запустите приложение:

```bash
python main.py
```

4. Откройте сайт в браузере:

```text
http://127.0.0.1:5000
```

Приложение запускается на `0.0.0.0:5000`, поэтому локально его также можно открыть по адресу выше.

## Данные для входа

При первом запуске, если в базе данных нет пользователей, автоматически создается администратор:

```text
Логин: seller
Пароль: seller
```

Этот пользователь имеет роль `admin` и может добавлять, редактировать и удалять товары.

## Основные маршруты

- `/` - главная страница с каталогом товаров.
- `/login` - вход пользователя.
- `/register` - регистрация нового пользователя.
- `/logout` - выход из аккаунта.
- `/product/add` - добавление товара, доступно продавцу или администратору.
- `/product/<id>` - подробная страница товара.
- `/product/edit/<id>` - редактирование товара.
- `/product/delete/<id>` - удаление товара.
- `/product/delete-image/<id>` - удаление изображения товара.
- `/review/add/<product_id>` - добавление отзыва к товару.
- `/review/edit/<id>` - редактирование отзыва.
- `/review/delete/<id>` - удаление отзыва.
- `/order/<product_id>` - оформление заказа.
- `/orders` - список заказов текущего пользователя.
- `/seller/products` - список товаров продавца.

## Роли пользователей

В проекте используются три роли:

- `user` - обычный пользователь, может просматривать товары, оставлять отзывы и оформлять заказы.
- `seller` - продавец, может управлять товарами.
- `admin` - администратор, имеет доступ к управлению товарами и отзывами.

## База данных

Проект использует SQLite-базу данных:

```text
db/shop.db
```

Таблицы создаются автоматически при запуске приложения через SQLAlchemy. Подключение к базе данных находится в файле `data/db_session.py`.

Основные сущности:

- `User` - пользователи и их роли.
- `Product` - товары магазина.
- `ProductImage` - изображения товаров.
- `Review` - отзывы и оценки.
- `Order` - заказы пользователей.

## Загрузка изображений

Изображения товаров загружаются в папку:

```text
static/uploads/
```

Для безопасности имена файлов обрабатываются через `secure_filename`. Максимальный размер загружаемых данных ограничен 50 МБ.
